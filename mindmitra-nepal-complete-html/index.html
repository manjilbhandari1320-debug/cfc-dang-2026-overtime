About MindMitra Nepal

Designed for organizations, built around personal privacy.

Organizations create temporary accounts for students or employees. Users set a private password, accept consent terms, and complete a detailed assessment. AI creates a supportive summary and, when required, a separate counsellor-facing report.

Privacy & Safety

Sensitive information deserves strong protection.

Supabase Authentication, PostgreSQL and Row Level Security separate access by role. Organizations cannot read private assessments. Counsellors access only assigned and consented reports.
